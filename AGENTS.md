customization for [`kborovik/gcp-acu-coa`](https://github.com/kborovik/gcp-acu-coa).

[`kborovik/acumatica-cli`](https://github.com/kborovik/acumatica-cli).
Create github issue in that repo, not here to fix CLI defects.
